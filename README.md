# Student Record Management System

## Project Description

The Student Record Management System is a menu-driven C programming project developed to manage student information efficiently.

The system stores student records using a linked list and provides options to add, display, modify, delete, search, sort, save, and load student records.

## Features

- Add a new student record
- Automatically assign a roll number
- Display all student records
- Delete a record using roll number
- Delete a record using student name
- Modify student name
- Modify student percentage
- Search records by roll number
- Search records by name
- Search records by percentage
- Sort records by name
- Sort records by percentage
- Save records to a file
- Load records from a file
- Input validation for student details

## Student Details

Each student record contains:

- Roll Number
- Student Name
- Percentage

## Technologies and Concepts Used

- C Programming
- Structures
- Linked List
